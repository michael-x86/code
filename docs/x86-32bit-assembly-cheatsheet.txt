═══════════════════════════════════════════════════════════════
              32-BIT x86 ASSEMBLY CHEAT SHEET
              ────────────────────────────────
                michael-x86/code  (this OS)
              NASM flat binary, no libc, no ELF
═══════════════════════════════════════════════════════════════

This project is a 32-bit x86 OS: BIOS → bootloader → 32-bit
protected mode → paging → higher-half kernel → int 0x80
syscalls → userland programs in /bin. All sources are NASM
flat binaries, linked with `nasm -f bin`. The OS has 36
syscalls, 16 built-in shell commands, and 25 userland
programs in /bin/. This cheatsheet is the project-specific
reference for writing kernel and userland code here.

  Source layout
  ─────────────
  bootloader.asm                BIOS → 32-bit, GDT, paging off
  kernel/  constants.inc        selectors, ports, syscall nums
  kernel/  syscall.inc          int 0x80 dispatcher + handlers
  kernel/  shell.inc            built-in shell command table
  commands/  *.asm              userland programs (one .asm each)
  build/  asm                   build script (the real one)

  Build & run
  ───────────
  ./asm                         build only
  ./asm -r                      build + run in QEMU window
  ./asm -f                      build + run fullscreen
  ./asm -d                      build + GDB on :1234, halt at start
  ./asm -h                      show help
  ./asm -i                      build code search index (and exit)

PART 1 ── THIS PROJECT'S REGISTERS AND ABI
═══════════════════════════════════════════════════════════════

── REGISTERS (i386) ───────────────────────────────────────────

  32-bit    16-bit   8-bit     Role in this project
  ──────────────────────────────────────────────────────────
  eax       ax       ah/al     Syscall number (input) / return value
                                 of every int 0x80 call. Also the
                                 primary accumulator in arithmetic.
  ebx       bx       bh/bl     Syscall arg 1. Holds file path
                                 buffers, byte count for sys_write,
                                 hex addr for sys_peek / sys_poke /
                                 sys_read_mem / sys_write_mem.
  ecx       cx       ch/cl     Syscall arg 2. Hold count for
                                 sys_write / sys_print_n, byte value
                                 for sys_poke / sys_write_mem, decimal
                                 string for sys_asc2int result usage.
  edx       dx       dh/dl     Syscall arg 3. Return high half of
                                 mul/div (edx:eax). Used for I/O
                                 port numbers in kernel PIO code.
  esi       si       —         Syscall arg 4. Pointer to NUL-terminated
                                 string for sys_print / sys_print_cr /
                                 sys_chdir / sys_create / sys_unlink /
                                 sys_mkdir / sys_rmdir / sys_write /
                                 sys_stat / sys_print_n / sys_hex2int.
  edi       di       —         Syscall arg 5. Destination buffer for
                                 sys_getcwd / sys_list_dir / sys_get_arg
                                 / sys_stat / sys_get_config / sys_itoa.
  ebp       bp       —         Syscall arg 6 (rare). USERLAND: holds
                                 the program's runtime base vaddr for
                                 the entire run (see USERLAND BINARY
                                 ABI below). KERNEL: frame pointer in
                                 functions that use locals.
  esp       sp       —         Stack pointer. Implicitly preserved
                                 across syscalls. The kernel does NOT
                                 push a return address for int 0x80;
                                 the userland program does `ret` to
                                 go back to exec_bin.

  Segment:   cs (code) ds/es/ss (data, flat)  fs/gs (unused)
  EIP        next instruction
  EFLAGS     flags (CF ZF SF OF PF AF DF IF …)

  ── Register role in this kernel's handlers (syscall.inc) ──
  Each syscall_isr pushes edi, esi, edx, ecx, ebx, ebp in that
  order before calling the handler, and pops them back in the
  reverse order before iretd. Handlers can therefore trash any
  of the five arg registers freely. Handlers must NOT pop
  eip/eipd — use iretd, not ret.

  ── Register role in the userland loader (exec.inc) ──
  exec_bin allocates a virtual range with find_free_virt, copies
  the binary into it, then `call eax`s [exec_vbase]. On return
  (`ret`), exec_bin recycles the pages and re-draws the prompt.


── USERLAND BINARY ABI (every commands/*.asm follows this) ───

  The kernel loader places each program at an ARBITRARY
  virtual address. Programs must be position-independent.

  Rule 1 — Anchor ebp on entry
  ────────────────────────────
  The first instruction of every program MUST be:

      _start:
          call .get_base
      .get_base:
          pop ebp
          sub ebp, .get_base
          ; … your code, ebp is now the program's load vaddr …

  Mechanism:
    1. `call .get_base` pushes the return address (the
       absolute runtime address of the next instruction).
    2. `pop ebp` pulls that address into ebp.
    3. `sub ebp, .get_base` subtracts the file offset of
       .get_base (always 5 in the standard pattern) so ebp
       becomes the program's load address — not the return
       address. .get_base is 5 bytes: e8 00 00 00 00.

  After this prologue, ebp is the load vaddr for the whole
  run. Treat it as read-only — never push, pop, or modify it.

  Rule 2 — Use lea reg,[ebp + label] for every data reference
  ─────────────────────────────────────────────────────────────
  | FORBIDDEN                        | REQUIRED                       |
  |----------------------------------|--------------------------------|
  | mov esi, msg                     | lea esi, [ebp + msg]           |
  | mov edi, buf                     | lea edi, [ebp + buf]           |
  | mov al, [usage_msg]              | mov al, [ebp + usage_msg]      |
  | mov [stat_buf], eax              | mov [ebp + stat_buf], eax      |
  | cmp dword [info], 0              | cmp dword [ebp + info], 0      |

  Numeric immediates are fine: `mov eax, 1`, `mov ecx, 26`.
  Only label references need the indirection.

  Rule 3 — Buffers in the file, not in section .bss
  ──────────────────────────────────────────────────
  The loader copies file_size bytes from disk into the first
  mapped page and does NOT zero the rest. Anything in
  `section .bss` lands in uninitialized memory (whatever the
  page allocator last had in that frame) — not safe to use.

  Use trailing `times N db 0` blocks in .text (or in
  .rodata) instead:

      align 4
      arg_buf:  times 128 db 0   ; in-file zero buffer

  Rule 4 — End with `ret`
  ───────────────────────
  `ret` returns control to exec_bin, which recycles the
  pages and redraws the prompt. Don't `hlt` or `jmp $`.

  Maximum program size: 4 KB (one page). The build script
  rejects anything larger. If you need more working space,
  call sys_alloc_pages (int 0x80 with eax=23, ecx=bytes) —
  the returned vaddr is yours to keep for the duration of
  the run and is freed automatically when you `ret`.


── KERNEL SYSCALL ABI (int 0x80) ─────────────────────────────

  Mechanism: trap gate at INT 0x80, DPL=3 (IDT_DPL3 = 0xEF).
  Interrupts are OFF while a syscall handler runs.

  Register contract
  ─────────────────
  eax = syscall number (input), return value (output)
  ebx = arg 1   (file path / byte count / hex addr / char / …)
  ecx = arg 2   (length / byte value / …)
  edx = arg 3
  esi = arg 4   (most often: pointer to NUL-term string)
  edi = arg 5   (most often: pointer to destination buffer)
  ebp = arg 6   (rare — used by a few FS calls)

  Caller-saved across the syscall: eax (return value).
  All other GPRs are preserved by every handler.

  Bad syscall number (eax >= SYSCALL_COUNT = 36) returns -1.
  Each handler returns -1 on its own failure path, 0 (or a
  positive value) on success. There is no errno.

  Calling sequence (NASM)
  ───────────────────────
      mov  ebx, 1              ; arg 1
      mov  esi, msg_addr       ; arg 4
      mov  eax, 1              ; sys_print
      int  0x80
      ; eax = 0 on success, -1 on failure


── KERNEL MEMORY MAP (after paging) ──────────────────────────

  0x00000000 + 0x00100000   0–1 MB   BIOS, VGA low alias (identity-mapped)
  0x00100000 + 0x00400000   1–4 MB   kernel low alias
  0x00400000                4 MB     kernel image (low copy, identity-mapped)
  0x00800000                8 MB     heap region 0
  0x00C00000               12 MB     heap region 1
  0x01000000               16 MB     heap region 2 (allocator pool ends here)
  0x000B8000               B8000     VGA text framebuffer (physical)

  After paging, all kernel code uses the higher-half mirror:
  0xC00B8000               VGA text framebuffer (use this)
  0xC0100000               kernel image (entry / code / data / bss)
  0xC0800000  … 0xC1400000  heap (12 MB, backed by three PDEs)
                            (PDE 770..772; pages handed out page-on-demand)
  0xC0000000  … 0xC0400000  low 4 MB mirror (VGA + boot handoff)

  Bootloader: physical 0x7C00, runs in real mode first, then
              16-bit protected mode with a temporary GDT,
              then jumps to 32-bit kernel entry at 0xC0100000
              (after copying the kernel to 0x00100000 first).

  page_bitmap (32 KB in BSS) tracks ownership of 1 GB of 4 KB
  physical frames. The userland loader hands out ranges from
  heap_start (0xC0800000) upward via find_free_virt.

  Source of truth: kernel/src/includes/constants.inc.

  5  print_hex      ebx=value              0

  ── Input / time / shutdown (7–9) ──────────────────────────

  34 peek           ebx=addr               byte at [ebx]

═══════════════════════════════════════════════════════════════
PART 3 ── BUILT-IN SHELL COMMANDS (kernel-side, in cmd_table)
═══════════════════════════════════════════════════════════════

  Source: kernel/src/includes/commands.inc → cmd_table
  These run in ring 0 (kernel mode). They are dispatched by
  dispatch_command in shell.inc when argv[0] matches. If no
  built-in matches, exec_bin looks up the name in /bin/.

  Built-ins (in dispatch order)
  ─────────────────────────────
  peek         display 16 bytes at the 0xDEADBEEF magic.
               (16 bytes, hex, space-separated)
  regs         print saved register set via show_regs.
               Shows eax ecx edx ebx esp ebp esi edi as
               hex dwords, with a 4-byte label prefix.
  stack        show_stack: top 8 dwords of the current stack.
  clear        cls: clear VGA screen, home cursor.
  quit         shutdown (alias for exit).
  exit         shutdown (calls sys_shutdown equivalent).
  help         print built-in help text via help_msg.
  echo         print argv[1] followed by newline.
  alloc        allocate heap pages.
               argv[1] = decimal page count → find_free_virt +
               alloc_page + map_page each. Prints "heap
               pointer : 0xXXXXXXXX" on success.
  free         release a previous allocation.
               argv[1] = hex base vaddr; looked up in
               alloc_table. Prints "memory released" or
               "invalid allocation".
  heap         walk alloc_table, print every live base
               vaddr in 0xXXXXXXXX form, then total free
               bytes via calc_free_heap.
  sys          int 0x80 self-test: prints sys_peek_msg, then
               sys_read_mem of the string pointer, then
               sys_print_hex. If wired up, you'll see
               "peek = 0x6B656570" (ASCII 'peek').
  fsdump       dump FS superblock fields, then walk every
               in-use inode and print its type/size/direct
               block pointers. For directories, also prints
               the child entries indented.
  fsck         verify every in-use inode's CRC-16 with
               verify_inode. Reports each corrupt inode
               number and a final tally, or "fsck: clean".
  ls           list cwd. Calls sys_list_dir (eax=13) with
               incrementing index until it returns -1.
               Appends '/' to directory entries.
  cd           change directory.
               argv[1] = path, or "cd" alone → "/root".
               Calls sys_chdir; on failure prints
               "cd: no such directory".

  Notes
  ─────
  • All built-ins read arguments from the parser-populated
    argv[] table, not from raw shell input.
  • `ls` and `cd` are duplicated: they also exist in the
    userland commands list (per the COMMANDS array in
    build/asm), but the source files commands/ls.asm and
    commands/cd.asm do not exist, so the build script
    skips them and the kernel built-in is the one that runs.
  • `help` is the kernel built-in. commands/help.asm is a
    separate userland program with a different message.

PART 4 ── USERLAND PROGRAMS (compiled from commands/*.asm)
═══════════════════════════════════════════════════════════════

  Source:  commands/<name>.asm
  Output:  build/bin/<name>
  Limit:   64 KB (the build script rejects anything larger)
  Loader:  exec_bin in kernel/src/includes/exec.inc
  Returns to shell via `ret` (loader recycles the page).

  The build is driven by the COMMANDS array in build/asm:

      COMMANDS=(exit help env dump alloc dealloc poke peek
                ps vi pwd ls cd ping cat touch write
                rm rmdir mkdir cp mv calc invaders zork)

  ── Userland programs at a glance ───────────────────────────

  Program     Args                  Description
  ──────      ────                  ───────────
  exit        —                     sys_shutdown (eax=9)
  help        —                     print the help banner
                                     (commands/help.asm)
  env         —                     print /etc/config values
                                     via sys_get_config (eax=30)
                                     keys 0..3 → timezone /
                                     datefmt / timefmt / layout
  dump        <hexaddr> <hexcount>  hex dump (16 bytes/line)
                                     uses sys_hex2int (eax=26)
                                     and sys_print_hex (eax=5)
                                     directly via print_hex_dword
  alloc       <pagecount>           sys_alloc_pages (eax=23)
                                     prints base vaddr
  dealloc     <hexaddr>             sys_free_pages (eax=24)
  poke        <hexaddr> <hexbyte>   sys_write_mem (eax=25)
                                     writes one byte
  peek        <hexaddr>             sys_hex2int (eax=26) on
                                     the string, then `int 0x80`
                                     with the parsed byte (in
                                     practice: read 1 byte)
  ps          —                     sys_get_ps_info (eax=22)
                                     + sys_get_proc_info (eax=28)
                                     prints current task, per-task
                                     ESPs, and current userland
                                     process info
  vi          <file>                modal editor
                                     HJKL = move, i = insert,
                                     x = delete, w = write, q = quit
                                     reads via sys_stat / sys_print_n,
                                     writes via sys_create / sys_write
  pwd         —                     sys_getcwd (eax=11) + print
  ping        —                     prints canned ping output
                                     (no real ICMP — just smoke
                                     test that print works)
  cat         <file>                sys_get_arg → sys_stat
                                     (must be a regular file) →
                                     sys_print_n (eax=16)
                                     renders \n as newline, \t
                                     as space
  touch       <file>                sys_get_arg → sys_create
  write       <file> <text...>      join argv[2..] with spaces,
                                     append \n, then sys_write
                                     (eax=18)
  rm          <file>                sys_stat (must be type 1) →
                                     sys_unlink (eax=19)
  rmdir       <dir>                 sys_stat (must be type 0) →
                                     sys_rmdir (eax=21)
  mkdir       <dir>                 sys_mkdir (eax=20)
  cp          <src> <dst>           copy a regular file
  mv          <src> <dst>           rename by copy + unlink
  calc        <num1> <op> <num2>    simple 32-bit unsigned int
                                     calculator, supports + - * / %
                                     and combined form "2+2"
                                     uses sys_asc2int (eax=27)
                                     and sys_print_int (eax=6)
  invaders    —                     Space Invaders in text-mode
                                     VGA, A/D = move, Space = fire,
                                     Q = quit
  zork        —                     interactive fiction (~26 KB)
  argtest     <args...>             print each arg on its own
                                     line. NOT in the default
                                     COMMANDS array — append
                                     "argtest" to enable.

  ── Typical program template (use this for new commands) ────

      ; mycmd — one-line description
      [bits 32]
      [org 0x00000000]

      _start:
          call .get_base
      .get_base:
          pop ebp
          sub ebp, .get_base

          ; --- fetch argv[1] ---
          mov ebx, 1
          lea edi, [ebp + arg_buf]
          mov eax, 14         ; sys_get_arg
          int 0x80
          cmp eax, -1
          je .usage

          ; --- do the work ---
          ; (use lea reg,[ebp + label] for all data refs)

          ret

      usage_msg: db "usage: mycmd ...", 13, 0

      ; --- in-file zero buffers, NOT section .bss ---
      align 4
      arg_buf: times 128 db 0

  ── Common arg-fetch boilerplate ────────────────────────────

      mov ebx, N                ; argv index (0 = program name)
      lea edi, [ebp + arg_buf]  ; destination buffer
      mov eax, 14               ; sys_get_arg
      int 0x80
      cmp eax, -1
      je .no_arg                ; or .usage

  ── Common path → "stat then act" pattern ───────────────────

      lea esi, [ebp + path_buf]
      lea edi, [ebp + stat_buf] ; 12 bytes
      mov eax, 15               ; sys_stat
      int 0x80
      cmp eax, -1
      je .not_found
      cmp dword [ebp + stat_buf], TYPE    ; 0=dir, 1=file
      jne .wrong_kind

  ── Parsing a number (hex) ──────────────────────────────────

      lea esi, [ebp + num_buf]
      mov eax, 26               ; sys_hex2int
      int 0x80
      ; eax = parsed dword (accepts 0x prefix, both cases)

  ── Parsing a number (decimal) ──────────────────────────────

      lea esi, [ebp + num_buf]
      mov eax, 27               ; sys_asc2int
      int 0x80

  ── Printing a hex dword ────────────────────────────────────

      mov ebx, my_value
      mov eax, 5                ; sys_print_hex
      int 0x80

  ── Printing a decimal dword ───────────────────────────────

      mov ebx, my_value
      mov eax, 6                ; sys_print_int
      int 0x80


═══════════════════════════════════════════════════════════════
PART 5 ── x86 INSTRUCTION QUICK REFERENCE
═══════════════════════════════════════════════════════════════

── DATA SIZES ─────────────────────────────────────────────────

  byte    = 8 bits    (db / resb)
  word    = 16 bits   (dw / resw)
  dword   = 32 bits   (dd / resd)
  qword   = 64 bits   (dq / resq)
  tword   = 80 bits   (dt / rest) — x87 only

── ADDRESSING MODES ──────────────────────────────────────────

  mov eax, [ebx]              ; base
  mov eax, [ebx + 4]          ; base + displacement
  mov eax, [ebx + ecx*4]      ; base + index*scale
  mov eax, [ebx + ecx*4 + 8]  ; base + index*scale + disp
  mov eax, [label]            ; absolute address (kernel only)
  lea esi, [ebp + msg]        ; address-of (preferred for label refs)

  Scale: 1, 2, 4, or 8
  Any 32-bit GPR can be base or index (except ESP as index)

── DATA MOVEMENT ──────────────────────────────────────────────

  mov   dst, src              ; move
  movzx dst, src              ; zero-extend
  movsx dst, src              ; sign-extend
  lea   dst, [mem]            ; load effective address
  xchg  dst, src              ; swap
  cmovcc dst, src             ; conditional move (P6+)
  push  src                   ; push dword
  pop   dst                   ; pop dword
  pushad                      ; push all 8 GPRs (32 bytes)
  popad                       ; pop all 8 GPRs
  pushfd                      ; push EFLAGS
  popfd                       ; pop EFLAGS
  movsb/movsw/movsd           ; [esi] → [edi] (b/w/d)
  lds/les/lfs/lgs/lss         ; load far pointer (seg:off)

── ARITHMETIC ─────────────────────────────────────────────────

  add   dst, src              ; dst += src
  adc   dst, src              ; dst += src + CF
  sub   dst, src              ; dst -= src
  sbb   dst, src              ; dst -= src + CF
  inc   dst                   ; dst++
  dec   dst                   ; dst--
  neg   dst                   ; negate
  cmp   op1, op2              ; compare (sets flags only)

  mul   src                   ; unsigned: edx:eax = eax * src
  imul  src                   ; signed:   edx:eax = eax * src
  imul  dst, src              ; dst = dst * src
  imul  dst, src, imm         ; dst = src * imm
  div   src                   ; unsigned: eax=quot, edx=rem
  idiv  src                   ; signed version
  cdq                         ; sign-extend eax into edx:eax
  aaa/aas/aam/aad             ; ASCII adjust (BCD)
  daa/das                     ; decimal adjust (packed BCD)

── LOGICAL / BITWISE ──────────────────────────────────────────

  and   dst, src
  or    dst, src
  xor   dst, src              ; xor eax, eax = zero (preferred)
  not   dst
  test  op1, op2              ; AND w/o store (sets flags)

  shl   dst, count            ; shift left
  shr   dst, count            ; shift right (unsigned)
  sar   dst, count            ; shift right (signed)
  sal   dst, count            ; alias of shl
  rol   dst, count            ; rotate left
  ror   dst, count            ; rotate right
  rcl   dst, count            ; rotate through carry left
  rcr   dst, count            ; rotate through carry right
  shld  dst, src, count       ; double-precision shift left
  shrd  dst, src, count       ; double-precision shift right

  bsf   dst, src              ; bit scan forward
  bsr   dst, src              ; bit scan reverse
  bt    bit, base             ; bit test
  bts   bit, base             ; bit test and set
  btr   bit, base             ; bit test and reset
  btc   bit, base             ; bit test and complement

── FLAGS (EFLAGS) ─────────────────────────────────────────────

  CF Carry    ZF Zero      SF Sign       OF Overflow
  PF Parity   AF AuxCarry  DF Direction  IF Interrupt
  TF Trap     NT NestedTask  RF Resume  VM V86
  AC Alignment  VIF VIP    ID CPUID

  pushfd / popfd to read/write EFLAGS

── CONDITIONAL JUMPS ──────────────────────────────────────────

  Mnemonic       Condition               After CMP A, B
  ─────────────────────────────────────────────────────
  je / jz        ZF=1                    A == B
  jne / jnz      ZF=0                    A != B
  jg / jnle      ZF=0 && SF=OF           A > B  (signed)

  ja / jnbe      CF=0 && ZF=0            A > B  (unsigned)

  jb / jnae      CF=1                    A < B  (unsigned)
  jbe / jna      CF=1 || ZF=1            A <= B (unsigned)

── SEGMENTS & SELECTORS (this project) ───────────────────────

  Flat model. Bootloader installs a flat 4 GB GDT with code
  at 0x08 (CODE_SEG) and data at 0x10 (DATA_SEG). All
  data segments DS/ES/SS/FS/GS use 0x10. CS = 0x08 in
  the kernel. RPL = 0 throughout (no userspace yet —
  userland runs in ring 0 too, but uses the syscall
  interface for privilege boundary).

  DPL 0 = kernel. IDT_DPL3 (0xEF) is the gate byte for
  the INT 0x80 trap gate, letting userland (DPL=3) call
  the syscall.

── PAGING (this project) ─────────────────────────────────────

  4 KB pages, 32-bit two-level (PDE → PTE). Kernel paging
  set up in kernel/src/includes/paging.inc:

  - Identity-maps the first 4 MB (BIOS / VGA / boot handoff)
  - Higher-half mirror at 0xC0000000+ for kernel use
  - PTE flag = PAGE_PRESENT_RW = 3 (present + R/W, no user
    bit — ring 0 only)
  - Page-on-demand heap backed by PDE 770..772 (12 MB)

  Layout:
    [PDE 10][PTE 10][offset 12]
    PDE → page table base, PTE → physical page base
    PDE/PTE flags: P, R/W, U/S, PWT, PCD, A, D, PS

  CR0: PE (protected), PG (paging), ET, WP, AM, …
  CR2: faulting linear address (on #PF)
  CR3: page directory physical address (PDBR)
  CR4: PSE, PAE, MCE, OSFXSR, OSXMMEXCPT

PART 6 ── COMMON PATTERNS (this project)
═══════════════════════════════════════════════════════════════

── USERLAND PROGRAM LIFECYCLE ───────────────────────────────

  exec_bin (kernel/src/includes/exec.inc) does roughly:

      find_free_virt       ; pick a free page-aligned vaddr
      map all 4 KB pages   ; identity-map from that range
      ; copy file_size bytes from disk to the new vaddr
      mov eax, [exec_vbase]
      call eax             ; run _start
      ; on ret, free_pages(exec_vbase), re-prompt

  Implications for your program:
  • You only get 4 KB. If you need more, call sys_alloc_pages
    at run time (eax=23) and the loader does NOT free that —
    the kernel reclaims everything when you ret.
  • Your data must be in-file. Section .bss is unsafe.
  • You have no argc/argv in the conventional sense. Use
    sys_get_arg (eax=14) to read individual arguments, and
    sys_get_arg with ebx=0 to get your own program name.
  • You do not get a stack segment — there's no separate
    user stack. Calls in userland share the kernel's stack
    while exec_bin is on it. Keep your call depth small.

── KERNEL FUNCTION PROLOGUE / EPILOGUE ──────────────────────

      push ebp
      mov  ebp, esp
      sub  esp, N          ; N bytes of locals
      ; … body …
      mov  esp, ebp
      pop  ebp
      ret

  Access stack args (cdecl, after prologue):
      mov  eax, [ebp+8]    ; arg1 (return address is at [ebp+4])
      mov  eax, [ebp+12]   ; arg2
  Local vars:
      mov  eax, [ebp-4]    ; local 1
      mov  eax, [ebp-8]    ; local 2

── LOOP / BRANCH / SWITCH PATTERNS ──────────────────────────

  Loop (i = 0; i < N; i++):
      xor  ecx, ecx
  .loop:
      ; … body …
      inc  ecx
      cmp  ecx, N
      jl   .loop

  While loop:
  .top:
      test eax, eax
      jz   .done
      ; … body …
      jmp  .top
  .done:

  If / else:
      cmp  eax, ebx
      jne  .else
      ; … if body …
      jmp  .endif
  .else:
      ; … else body …
  .endif:

  Switch (jump table):
      cmp  eax, MAX_CASE
      ja   .default
      jmp  [jump_table + eax*4]
  .case0: …
  .case1: …

  Min / Max:
      cmp  eax, ebx
      jle  .no_swap
      xchg eax, ebx
  .no_swap:

  Absolute value:
      cdq                  ; edx = sign mask of eax
      xor  eax, edx
      sub  eax, edx

  Sign extend:
      movsx eax, byte [val]  ; byte → dword
      movsx eax, word [val]  ; word → dword

  String length:
      mov  edi, str
      xor  ecx, ecx
      not  ecx             ; ecx = -1
      xor  al, al
      repne scasb
      not  ecx
      dec  ecx             ; length in ecx

  Memory copy:
      mov  esi, src
      mov  edi, dst
      mov  ecx, len
      rep  movsb

  Struct member access:
      mov  eax, [ebp+8]    ; struct ptr
      mov  ebx, [eax+12]   ; member at offset 12

── ZERO / PUSH-POP IDIOMS ──────────────────────────────────

  Zero a register:
      xor  eax, eax        ; preferred (3 bytes, no dependency)

      ; or: sub eax, eax

  ── Conventions used in this project ──
