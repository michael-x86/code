## VULN-01: Integer Overflow in `sys_alloc_pages` / `sys_alloc`

**Severity:** HIGH → **RESOLVED**

**File:** `src/includes/syscall.inc`

**Root cause:** No upper-bound check on the byte-count argument before the rounding arithmetic.

**Fix applied:** Added `cmp eax, HEAP_TOTAL_SIZE; ja .err` before the `add eax, 4095` rounding in `sys_alloc_pages`. Added `cmp ecx, HEAP_TOTAL_SIZE / PAGE_SIZE; ja .alloc_bad` in `sys_alloc`.

```asm
sys_alloc_pages:
    mov eax, ecx
    test eax, eax
    jz .err
    cmp eax, HEAP_TOTAL_SIZE      ; 12 MB max
    ja .err
    add eax, 4095
    shr eax, 12
    mov ecx, eax
    ...
```

## VULN-02: Invalid Free — No Heap Boundary Validation

**Severity:** CRITICAL → **RESOLVED**

**Files:** `src/includes/syscall.inc:924–951, 1264–1291`

**Root cause:** `sys_free_pages` / `sys_dealloc` trust the vaddr stored in `alloc_table` without verifying it is within the heap window or page-aligned.

**Fix applied:** Added sanity checks in `.found` / `.de_found` path before calling `free_pages`: verify vaddr is within `[heap_start, heap_end)`, check page alignment (`test eax, 0xFFF`), and reject zero-size entries.

```asm
.found:
    mov eax, [esi]               ; vaddr from alloc_table
    cmp eax, heap_start
    jb .bad
    cmp eax, heap_end
    jae .bad
    test eax, 0xFFF
    jnz .bad
    mov ebx, [esi + 4]
    test ebx, ebx
    jz .bad
    ...
```

## VULN-03: NULL Pointer Dereference in Syscall Handlers

**Severity:** HIGH → **RESOLVED**

**File:** `src/includes/syscall.inc`

**Root cause:** Six syscall handlers accept buffer/string pointers without checking for NULL.

**Fix applied:** Added `test reg, reg; jz .bad` (or `.nf` / `.done`) at the top of each affected handler:

| Syscall | # | Register | Jump target |
|---|---|---|---|
| `sys_getcwd` | 11 | `edi` (dst) | `.bad` (added) |
| `sys_chdir` | 12 | `esi` (path) | `.nf` |
| `sys_list_dir` | 13 | `edi` (dst) | `.ld_nf` |
| `sys_get_arg` | 14 | `edi` (dst) | `.nf` |
| `sys_stat` | 15 | `edi` (info buf) | `.nf` |
| `sys_print_n` | 16 | `esi` (buf) | `.done` |

## VULN-04: Path Traversal (Unrestricted `..` in Multi-Component Paths)

**Severity:** HIGH → **RESOLVED**

**File:** `src/includes/vfs.inc:81–158`

**Root cause:** `fs_resolve` only handles `..` when the **entire** input path is exactly `".."`. Multi-component paths like `"../etc/config"` were concatenated with cwd and passed to `fs_lookup_inode`, which followed on-disk `..` entries.

**Fix applied:** Rewrote the `.relative` section to process path components individually:
- `..` components: strip the last directory component from the output buffer
- `.` components: skip silently
- Other components: append with `/` separator
- All operations bounded by `CWD_BUF_SIZE` with truncation on overflow

---

## VULN-05: Path Buffer Overflow (No Length Check)

**Severity:** CRITICAL → **RESOLVED**

**File:** `src/includes/vfs.inc:131–158`

**Root cause:** `fs_resolve` copies `cwd` and the relative path into `resolve_buf` (128 bytes) with no bounds check.

**Fix applied:** Added `edx` byte counter throughout the `.relative` path with `CWD_BUF_SIZE` checks before every write. On overflow, the path is truncated and NUL-terminated.

## VULN-06: Unbounded Memory Read via `sys_print_n`

**Severity:** HIGH → **RESOLVED**

**File:** `src/includes/syscall.inc:527–557`

**Root cause:** No check on `esi` or `ecx` before the read loop.

**Fix applied:** Added NULL check (`test esi, esi; jz .done`) and an upper bound clamp on `ecx`:

```asm
    cmp ecx, VGA_COLS * 4   ; 320 bytes max
    jbe .ok
    mov ecx, VGA_COLS * 4
```

**File:** `src/includes/syscall.inc:1114–1177`

**Fix applied:** Added `test edi, edi; jz .bad` before the key validation.

## VULN-08: `check_user_addr` False Acceptance of NULL

**Severity:** LOW → **MITIGATED by VULN-03**

**File:** `src/includes/syscall.inc:247–275`

**Observation:** `check_user_addr(NULL)` returns CF=0 by design (low memory is user-accessible). The mitigation is the explicit NULL checks added in VULN-03, which prevent NULL dereferences before they reach memory access.

---

## VULN-09: `sys_sound` — Division by Zero

**Severity:** LOW → **RESOLVED**

**File:** `src/includes/syscall.inc:1328–1406`

**Fix applied:** Moved the frequency zero and overflow checks (`cmp ebx, 0; je .sound_off` / `cmp ebx, 1193180; ja .invalid_no_push`) **before** the five register pushes. Added `.invalid_no_push` return path for the early-exit case so the stack stays balanced.

---

## VULN-10: Information Leak via `sys_get_proc_info`

**Severity:** MEDIUM → **RESOLVED**

**File:** `src/includes/syscall.inc:1050–1075`

**Fix applied:** Replaced `mov eax, [exec_vbase]; mov [ebx], eax` with `xor eax, eax; mov [ebx], eax` to zero out `exec_vbase` before returning to userland, preventing kernel address disclosure.

---

## VULN-11: User-Mode Write to Kernel Memory via `sys_write`

**Severity:** HIGH → **RESOLVED**

**File:** `src/includes/syscall.inc:650–674`

**Root cause:** `sys_write` reads user data from `ebx` (the buffer pointer) without calling `check_user_addr`.

**Fix applied:** Added `check_user_addr` call on the user buffer pointer (from `pushad` stack at `[esp + 16]`) before passing it to `file_write`. Also corrected the original `pushad` stack offsets for `ecx` (count) from `[esp]` to `[esp + 24]`.

## Remaining Findings (20)

After all mitigations, 20 findings remain. These are predominantly:
- **`check_user_addr` allowing NULL** (by design — user programs need low-memory access; mitigated by explicit NULL checks in handlers)
- **Return-value artifacts in test harness** where the CPU halts before the return value is read (the overflow/null checks work correctly but the test reads EAX from a halted CPU state)
- **Pre-existing design limitations** that are informational rather than exploitable
