## Architecture at a glance

- **Bootloader** (`bootloader.asm`) — enables A20, checks for `int 13h` LBA support, loads the kernel one sector at a time into a buffer, enters protected mode, relocates the kernel to `0x00100000`, and jumps to it.
- **Kernel** (`kernel.asm` + `kernel_*.inc`) — paging identity-maps the first 4 MB **and** maps it at `0xC0000000+`. Installs IDT/PIC/PIT/keyboard/syscall handlers, loads the persisted filesystem, runs the login gate, then schedules processes; slot 2 is the shell.
- **Filesystem** (`fs.inc`, auto-generated by `generate-fs.py`) — embedded as fixed-size 68-byte records inside the kernel image, each non-dir entry backed by a 2048-byte mutable buffer. 32 "spare slots" for runtime-created files.
- **Persistence** — modified spare slots are written through to a fixed region on the disk image (starting at LBA 512, 5 sectors per slot). A boot-time loader replays them into RAM.
- **Userland** — programs are assembled separately into ≤4 KB flat binaries (`[org 0x00000000]`), embedded in `/bin` at build time, and spawned into a process slot when invoked. They talk to the kernel only via `int 0x80`.

## Kernel module layout

`kernel.asm` keeps the entry path (Multiboot header, boot GDT, `page_mapping`, `kernel_main`, the three task entries) and `%include`s one file per subsystem:

| File | Subsystem |
|---|---|
| `kernel_clock.inc` | PIT, CMOS clock, tick banner |
| `kernel_kprint.inc` | VGA text printing helpers |
| `kernel_kbd.inc` | keyboard buffer + IRQ1 |
| `kernel_shell.inc` | prompt, line editor, history, dispatch, tab completion, `run` |
| `kernel_login.inc` | login gate |
| `kernel_mm.inc` | page allocator, heap, page fault |
| `kernel_idt.inc` | IDT, IRQ gates, `int 0x80` entry |
| `kernel_syscall.inc` | syscall wrappers (userland API) |
| `kernel_vfs.inc` | in-kernel VFS syscalls |
| `kernel_disk.inc` | ATA PIO + FS persistence |
| `kernel_sched.inc` | process table, round-robin scheduler |
| `kernel_exec.inc` | `/bin` loader (userland programs) |
| `kernel_gfx.inc` | VBE/VGA graphics modes |
| `kernel_mandel.inc` | Mandelbrot/dydx demos |
| `kernel_data.inc` / `kernel_rodata.inc` / `kernel_bss.inc` | sections `.data` / `.rodata` + embedded FS / `.bss` |

To add a userland-facing feature: syscall wrapper in `kernel_syscall.inc` (or `kernel_vfs.inc`/`kernel_mm.inc` for FS/memory), table entry in `syscall_table` (`kernel_data.inc`), command in `commands/` + `COMMANDS` in the `Makefile`.
