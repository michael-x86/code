About x86 Web Emulator

An x86 (i386+) PC emulator in the browser, adapted from Zeal 8-bit Web Emulator.

Runs a custom x86 OS kernel with protected mode, paging, VGA text mode, and more.

Source code: github.com/anomalyco/code

Licence

The CPU core and emulator files are distributed under the Apache 2.0 License.

Getting started

  1. Kernel/disk image loading
  2. Emulated screen and PS/2 keyboard
  3. Bottom views: disassembler, memory viewer and serial terminal
  4. Debugging actions: start/resume CPU, step, reset
  5. Breakpoint management
  6. CPU registers value

Loading a kernel

Use the file uploads in the left panel to load a kernel binary and optional disk image.

Click "Load & Run" to load and start execution.
